# Reproducible Figures

This directory contains the final visual previews of the three TSP 1.0 figures and receives the derived outputs generated by the scripts in `src/`.

- **Figure 1:** canonical trajectories for `u0 = 0.2, 0.8, 1.8, 2.0, 2.2, 3.0`.
  - Preview: `figure_1_trajectories.svg`
  - Reproducible outputs from the script: `figure_1_trajectories.png` and `figure_1_trajectories.pdf`
- **Figure 2:** topological change around `kappa_c = 1.5625` for `chi=2.5`, `delta=1`.
  - Preview: `figure_2_bifurcation.svg`
  - Reproducible outputs from the script: `figure_2_bifurcation.png` and `figure_2_bifurcation.pdf`
- **Figure 3:** minimal structural-memory extension, comparing the same initial observable value `u0=1` with `m0=0` and `m0=0.7`.
  - Preview: `figure_3_structural_memory.svg`
  - Reproducible outputs from the script: `figure_3_structural_memory.png` and `figure_3_structural_memory.pdf`

The SVG files are lightweight repository previews. PNG and PDF files are deterministic derived products generated by the versioned scripts. The primary reproducible scientific sources remain the equations, parameters, numerical checks, and scripts stored in this repository.
